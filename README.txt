MI RITMO — LISTO PARA PUBLICAR EN UNA CUENTA SEPARADA DE VERCEL

Contenido: index.html, manifest.webmanifest, sw.js, vercel.json, icons/

Opción recomendada sin terminal:
1. Ingresá a una cuenta NUEVA de Vercel (no la de Trylines).
2. Creá un repositorio de GitHub nuevo, exclusivo para Mi Ritmo.
3. Subí todos los archivos del ZIP a la raíz de ese repositorio (incluida la carpeta icons).
4. En la cuenta nueva de Vercel: Add New -> Project -> Import Git Repository.
5. Seleccioná ese repositorio. Elegí Framework Preset: Other. No requiere Build Command.
6. Deploy. Abrí la URL pública desde Safari del iPhone.
7. Safari: Compartir -> Agregar a pantalla de inicio. Abrí la app desde el nuevo ícono.

IMPORTANTE: los registros se guardan únicamente en cada dispositivo/instancia instalada.
No se sincronizan entre Safari, otras pantallas de inicio y otros celulares.
Desde Mi Plan podés exportar o importar tus datos para hacer un respaldo.
Es una página estática: no necesita base de datos ni credenciales.
